Pumpkins Challenge

Each student receives a modified pumpkins.csv dataset (from real competition data).

Columns include

id, place, weight_lbs, grower_name, city, state_prov, country, gpc_site, seed_mother, pollinator_father, ott, est_weight, pct_chart, variety

Tasks

  1. Read in pumpkins.csv
  2. Identify the heaviest pumpkin (variety, location, year)
  3. Convert pounds → kilograms (weight_kg column)
  4. Add a weight_class column (light / medium / heavy)
  5. Plot estimated vs actual weight (coloured by class)
  6. Filter for three countries and save (pumpkins_filtered.csv)
  7. Summarise mean weights by country and variety
  8. Create a boxplot for the three countries
  9. Create a faceted plot by variety

Repository contents (Pumpkins)

  • script.R or script.py
  • requirements.txt
  • output.docx (answers + 3 plots)
  • pumpkins_filtered.csv
  • Completed Jupyter notebook

Submit both repos (Pumpkins + Gene Expression) as one zipped folder, with repo URLs.

Differential Gene Expression Challenge

You will write an R or Python script to analyse DESeq2 output.
You are not expected to run DESeq2 yourself.

Each TSV file includes:
- Gene identifiers
- Log fold changes
- P-values and adjusted p-values

Required outputs

Your report should include:

  • Summary statistics:
    • Up/downregulated gene counts
    • p-value and logFC summaries
  • Plots:
    • Volcano, MA, histogram, and heatmap
  • Tables:
    • Significant genes with logFC, p-values, and FDRs
  • Additional analysis:
    • Clustering, pathway, or QC insights

Repository contents (Gene Expression)

  • script.R or script.py
  • requirements.txt
  • output.docx (plots and commentary)

Submit both challenges together as a single zipped folder on Moodle, including both GitHub URLs.
