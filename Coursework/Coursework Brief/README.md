# LIFE4138 coursework

This directory contains instructions and resources for the coursework component of the LIFE4138 module.

Detailed instructions for this coursework are provided as a markdown document coursework.qmd

## Part 1

10 questions to be answered in both R and Python - these questions provided as jupyter notebooks: R_Coursework_Questions.ipynb and Python_Coursework_Questions.ipynb.  You must fill out and run the notebooks in the cells provided and save your completed notebooks.


## Part 2

Two Scripting challenges - Pumpkins and Gene Expression, one to be completed in R, one in Python. You may choose which language you use to complete which challenge.

Each challege has its own folder in this repo with data for each of you to use.

Each of you will complete the challenge using a different dataset. The datasets are numbered and you can find your allocated number in the file student_dataset_allocation_numnbers.txt in the main coursework directory of this Repo.

## Additional Info

Coursework submission deadline: Thursday 11th December 2025 by 3pm

Total weighting:

Part 1 & Part 2 R = 37.5% of module mark
Part 1 & Part 2 Python = 37.5% of module mark
